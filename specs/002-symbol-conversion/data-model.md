# Data Model: Преобразование символов из системных раскладок

**Дата**: 2026-09-25 | **План**: [plan.md](./plan.md) | **Исследование**: [research.md](./research.md)

Все сущности существуют только в памяти, пока обрабатывается одно нажатие хоткея. Ничего не
сохраняется на диск; ключи и формат `UserDefaults` не меняются.

## KeyStroke

Физическая клавиша в одном состоянии Shift.

| Поле | Тип | Правило |
|------|-----|---------|
| `keyCode` | `UInt16` | Код из набора для типа клавиатуры ([R1](./research.md#r1-откуда-брать-символ-клавиши)) |
| `shift` | `Bool` | `false` — без модификаторов, `true` — только Shift |

Порядок, `Comparable`: сначала `shift == false`, затем по возрастанию `keyCode`. На этом порядке
основано правило коллизий ([R4](./research.md#r4-правило-коллизий)).

## KeyboardKind

Тип клавиатуры. Определяет, какие клавиши физически существуют.

| Значение | Как определяется | Набор кодов |
|----------|------------------|-------------|
| `ansi` | `KBGetLayoutType == 'ANSI'` и неизвестные значения | `0...50` без `10, 36, 48, 49` |
| `iso` | `'ISO '` | как `ansi` + `10` |
| `jis` | `'JIS '` | как `ansi` + `93, 94` |

Вместе с видом хранится сырое значение `keyboardType: UInt32`, которое передаётся в `UCKeyTranslate`.

## KeyLayout

Одна раскладка на конкретном типе клавиатуры.

| Поле | Тип | Правило |
|------|-----|---------|
| `id` | `String` | ID источника ввода, например `com.apple.keylayout.RussianWin` |
| `keys` | `[KeyStroke: Character]` | Только клавиши, давшие ровно один печатный символ, не пробел |
| `script` | `Script` (`latin`, `cyrillic`, `other`) | По большинству букв среди символов без Shift ([R5](./research.md#r5-латинская-или-кириллическая-раскладка)) |

Создание:
- `KeyLayout.system(id:keyboardType:)` — из данных macOS; `nil`, если раскладки нет или у неё
  нет `uchr` (FR-002, Edge Cases). Вызывается только на главном потоке.
- Обычный инициализатор `KeyLayout(id:keys:)` — для синтетических тестов логики, без TIS.

Производные данные:
- `characters: Set<Character>` — все символы раскладки.
- `mapping(to target: KeyLayout) -> [Character: Character]` — для каждой клавиши, которая есть в
  обеих раскладках, по порядку `KeyStroke` добавляется пара `self.keys[k] → target.keys[k]`, если
  символ источника ещё не занят. Первая клавиша побеждает (FR-010).

## LayoutPair

Раскладки, участвующие в одном преобразовании.

| Поле | Тип | Правило |
|------|-----|---------|
| `latin` | `KeyLayout` | Первая раскладка со `script == .latin` в порядке выбранных |
| `cyrillic` | `KeyLayout` | Первая раскладка со `script == .cyrillic` в порядке выбранных |

Если одной из них нет, пары нет: текст не меняется.

Символы только одной раскладки (FR-004):
- `latinOnly = latin.characters − cyrillic.characters`
- `cyrillicOnly = cyrillic.characters − latin.characters`

## DirectionSource

Как определено направление. Пишется в журнал без текста (FR-013).

| Значение | Когда |
|----------|-------|
| `letters` | Во фрагменте есть буквы; большинство — латиница или кириллица |
| `layoutOnlySymbols` | Букв нет; все символы только одной раскладки указывают на одну раскладку |
| `currentLayout` | Букв и таких символов нет; текущая раскладка — одна из пары |
| `undetermined` | Ничья по буквам; символы указывают на разные раскладки; текущая раскладка не из пары; нет пары |

## ConversionResult

Результат `TextConverter.convert`. Заменяет нынешний кортеж `(converted, targetLayoutID)`.

| Поле | Тип | Правило |
|------|-----|---------|
| `converted` | `String` | Символы без соответствия остаются прежними |
| `targetLayoutID` | `String?` | `nil`, если направление не определено |
| `source` | `DirectionSource` | Для журнала |

`ReplacementFlow` по-прежнему считает результат заменой, только если `targetLayoutID != nil` и
`converted != source text` (FR-006, FR-007).

## Переходы при нажатии хоткея

```text
главный поток:  выбранные ID ─► KeyLayout.system(...) для каждого ─► [KeyLayout] + текущий ID
                                                                          │
replacementQueue:   выделение / копирование (фича 001) ─► TextConverter.convert(...) ─► ConversionResult
                                                                          │
                              targetLayoutID != nil && текст изменился ─► вставка + switchTo(target)
                              иначе                                    ─► layoutOnly + switchToNextLayout()
```

## LayoutCatalog (бывший `CharacterMap`)

Без словарей символов. Содержит:
- ID кириллических раскладок, которые предлагает popover, с исправленным белорусским ID
  `com.apple.keylayout.Byelorussian` ([R7](./research.md#r7-где-жили-ручные-таблицы-и-что-остаётся));
- список латинских ID, которые предлагает popover (без изменений);
- `displayName(for:)` для строки меню.

Каталог определяет только, что предлагается в «Active Keyboards». Роль раскладки в
преобразовании определяется `KeyLayout.script` по данным системы.
