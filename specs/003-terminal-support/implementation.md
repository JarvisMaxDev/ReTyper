# Актуальная реализация 003 — 2026-10-01

Эта редакция уточняет первоначальный дизайн 2026-09-29 и имеет приоритет над техническими
деталями старого плана, модели, контракта и задач. Исходные спайки в `verification.md` — история.

## Базовая линия и согласования

  встроенные терминалы не записываются. Проверка редактора сравнивается с 0.10.1, не с дефектом 0.10.0.

## Фрагмент и классификация

`TerminalReplacement.swift` содержит чистые типы `TypedFragment`, `TerminalKey`, `TerminalEdit`.
Предел — 256 символов. Переполнение очищает строку и приостанавливает накопление до сброса.
Флаг называется `isSuspended`: то же состояние используется для мёртвых клавиш, Option-ввода,
неизвестной раскладки и непроверяемой композиции. Простого сброса на dead key недостаточно:
следующая буква может завершить композицию и не соответствовать физической клавише.

Один запомненный символ — один Unicode scalar, не combining mark и не управляющий символ.
Это более узкое условие, чем один Swift `Character`: составной графемный кластер нельзя считать
одним Backspace. Результат преобразования проверяется по тем же ограничениям и длине.
`replaceTail` возвращает false для недопустимой длины, вместо аварийного precondition.

Enter, Tab, стрелки, Escape, перемещение, неизвестные функциональные клавиши и сочетания
Command/Control сбрасывают фрагмент. Fn/Globe и Caps Lock также инвалидируют запись.
Option+Backspace — сброс; Option-буква, Caps-ввод, dead key — приостановка до следующего сброса.
Shift выбирает системное соответствие. Таблицы конвертации не изменены; `deadKeys` читаются
дополнительным `UCKeyTranslate` с разрешённым dead-key state.

## Привязка к получателю

`TerminalRecorder` хранит фрагмент, кеш раскладок и `TerminalContext` (PID, время запуска,
AX-окно и фокусное поле типа AXTextArea, не secure field). AX нужен только для идентичности,
содержимое строки терминала не читается.

Первое печатное событие запускает фоновую привязку. Асинхронный результат проверяется по epoch
сброса, а не generation каждого символа: быстрый набор не отменяет собственную привязку.
AX-уведомления смены окна/поля, смена приложения/рабочего стола, мышь и отключение tap сбрасывают
состояние. При недоступных уведомлениях запись не начинается. Secure input проверяется на
каждом событии и каждые 50 мс в активном терминале; при включении строка очищается и накопление
приостанавливается. При выходе все объекты и наблюдатели освобождаются.

## Удержание ввода

Обычные приложения используют прежний `listenOnly` tap. Пока активен поддержанный терминал,
его события обрабатывает отдельный `defaultTap`; вне операции он пропускает события неизменными.
Пассивный tap не обрабатывает их повторно. Хоткей начинает `TerminalInputGate` прямо в активном
callback, а подготовку переносит на main queue. Включать перехват лишь перед первым Backspace
слишком поздно: живой сценарий Enter10 воспроизвёл отправку исходной строки до замены.

1. Начать hold на хоткее; повторный хоткей во время операции не ставится в очередь.
2. Вне callback получить преобразование; на replacement queue проверить прежние PID/launch,
   окно и поле и заранее создать всю последовательность событий.
3. На main проверить ticket, активный hold, revision, generation, PID, secure input и кнопки мыши.
   Невалидный контекст — отмена до удаления. Подготовка ограничена 300 мс, поздние ответы игнорируются.
4. Цельным ограниченным блоком на main отправить события через `CGEvent.postToPid` прежнему процессу.
   Сначала ровно N Backspace, затем Unicode-пары. Никаких Enter, выделения или clipboard.
   Свои события имеют прежний маркер ReTyper и не попадают в запись.
5. Обновить фрагмент, выбрать раскладку, дождаться наблюдаемого ID до 200 мс и отпустить очередь.
6. События пользователя воспроизвести с исходным payload по порядку. Новые события не обгоняют
   уже воспроизводимые. Метка содержит ticket; callback подтверждает доставку через наш tap.
   Watchdog 1 с предотвращает зависание, если secure input скрыл подтверждения; старый watchdog
   предыдущей волны не завершает следующую. При пачке 512 событий очередь освобождается досрочно.
7. Если во время операции пришла печатная клавиша, её результат после смены раскладки не угадывается:
   накопление приостанавливается до сброса. Enter при воспроизведении сам очищает фрагмент.

Отключение перехватывающего tap вне hold не является потерей ввода: его собственное уведомление
не должно сбрасывать успешно преобразованный фрагмент. При таймауте во время hold фрагмент сбрасывается,
очередь освобождается. В журнал допускаются только исход, длина, причина сброса и количество событий.

Ограничение: серия не является транзакцией чужого терминального процесса. Закрытие окна/процесса
или переключение получателя сторонней программой внутри уже начатой серии невозможно откатить.
Обычные клавиатурные/мышиные события удерживаются; произвольные полноэкранные программы не гарантируются.

## Проверка

- Unit-тесты: `TerminalReplacementTests.swift` (включая TypedFragment/TerminalKey),
  `TerminalInputGateTests.swift`; весь существующий набор редактора также обязателен.
- Терминальный драйвер вынесен в `Tools/ReTyperStand/TerminalDriver.swift`, вызывается через
  `bash Tools/ReTyperStand/run.sh --terminal --repeat 10 --out <путь>`.
- Драйвер использует системные KeyLayout и выставляет соответствующий Unicode в тестовом событии:
  конструктор CGEvent сам даёт US payload даже при выбранной русской раскладке. Физическая клавиатура
  дополнительно проверяется владельцем; синтетический прогон её не заменяет.
- Только собственные `.command`/`zsh -f`/`vared`, строка записывается как данные, не выполняется.
  Перед каждым вводом проверяются PID приложения и название тестового окна. Сохраняются/возвращаются
  раскладка, режим последнего слова и clipboard всех типов. Проверяется неизменность changeCount.
- Вывод fixture публикуется атомарным переименованием; готовность vared подтверждается из
  `zle-line-init`. После сценария подтверждается исчезновение собственного AX-окна, включая
  диалог завершения процессов. При ошибке cleanup прогон останавливается до открытия следующего
  окна; `defer` убирает fixture и при исключении. После запроса владельца об остановке массовые
  прогоны не возобновлять без предварительной проверки cleanup на одном окне и согласования.
- T1–T11, T13, TMax (256 символов), Typing0 (допечатанная клавиша), Enter0/10/30/80.
  Для Typing0 допустима исходная или новая раскладка допечатанного символа, но не смешанная/обрезанная строка.
  Enter-сценарии допускают неизменённый исходник лишь при явной отмене до удаления.
- Продолжительность считается от последнего отпускания Option до наблюдаемого исхода в журнале;
  содержимое, отправленное Enter в vared, проверяется отдельно. Это не измерение времени отрисовки.
- Результаты кандидата и оставшиеся ручные gates — в [verification.md](./verification.md).
