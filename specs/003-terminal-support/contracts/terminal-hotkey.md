# Контракт: хоткей в терминале

> Актуальный контракт 2026-10-01 — [implementation.md](../implementation.md).
> Он имеет приоритет над исходными деталями ниже. Ввод удерживается с callback хоткея,
> Enter доставляется после замены/отмены. Вместо `isOverflowed` — `isSuspended`; привязка
> окна/поля отдельная. Редакторная базовая линия — 0.10.1. Конституция — 9.0.0.

**Дата**: 2026-09-29 | **Модель**: [data-model.md](../data-model.md)

ReTyper не предоставляет API другим программам. Внешний контракт — наблюдаемое поведение хоткея в
терминале. Внутренний контракт — чистые функции между `KeyboardMonitor`, `AppDelegate` и новым
`TerminalReplacement`.

## Внешний контракт: что видит пользователь

Условия: активен Терминал macOS, выбраны латинская раскладка L и кириллическая C, защищённый ввод
выключен. «Фрагмент» — то, что напечатано в строке после последнего сброса
([R2](../research.md#r2-какие-нажатия-пополняют-фрагмент-какие-сбрасывают)).

| Ситуация | Строка после хоткея | Раскладка после |
|----------|---------------------|-----------------|
| Фрагмент пуст (ничего не набрано или был сброс) | без изменений | следующая |
| Набрано больше 256 символов после последнего сброса | без изменений | следующая |
| Фокусное окно терминала сменилось после начала фрагмента | без изменений | следующая |
| Защищённый ввод включён | без изменений | следующая |
| Направление не определено или результат равен фрагменту (правила фичи 002) | без изменений | следующая |
| Режим всей строки | фрагмент заменён преобразованным; текст до фрагмента не меняется | целевая |
| Режим последнего слова | последнее слово фрагмента (с пробелами после него) заменено | целевая |
| Повторный хоткей сразу после замены | исходный фрагмент | исходная |
| Приложения вне списка терминалов с заменой | как в v0.10.0 | как в v0.10.0 |

Буфер обмена ReTyper в терминале не использует. Если во время серии пользователь нажал клавишу,
результат не гарантируется ([R6](../research.md#r6-прерывание-во-время-замены-fr-009)).

Примеры для Polish Pro + Russian – PC:

| Строка до хоткея (жирное — фрагмент) | Режим | Строка после |
|--------------------------------------|-------|--------------|
| `% `**`ghbdtn`** | вся строка | `% привет` |
| `% `**`сгкд -Ш`** | вся строка | `% curl -I` |
| `% git commit -m `**`ghbdtn`** (фрагмент — вся команда) | последнее слово | `% git commit -m привет` |
| `% ls ` (из истории) + **`ghbdtn`** | вся строка | `% ls привет` |
| `% `**`ghbdtn`**, затем ← | любой | без изменений |

## Внутренний контракт

### `TerminalKey.classify`

```text
classify(keyCode: UInt16, flags: CGEventFlags, layout: KeyLayout?) -> TerminalKey
```

- `layout == nil` (у раскладки нет данных клавиш) → `.reset`.
- Флаги ⌘, ⌃, ⌥ или Caps Lock → `.reset`.
- Код 49 → `.character(" ")`; код 51 → `.backspace` (при флагах выше — `.reset`).
- `KeyStroke(keyCode, shift)` в `layout.deadKeys` или нет в `layout.keys` → `.reset`.
- Иначе `.character(layout.keys[stroke])`.

Чистая функция, без системных вызовов.

### `TerminalReplacement.edit`

```text
edit(fragment: TypedFragment, onlyLastWord: Bool,
     convert: (String) -> (converted: String, targetLayoutID: String?)) -> TerminalEdit?
```

- Пустой или переполненный фрагмент → `nil`.
- `source` = весь `fragment.text` либо `ReplacementFlow.lastWord(in:)`; пустой `source` → `nil`.
- `convert(source)` без целевой раскладки или с результатом, равным `source` → `nil`.
- Иначе `TerminalEdit(deleteCount: source.count, insert: converted, targetLayoutID: target)`.
- Если `converted.count != source.count` → `nil`: преобразование по клавишам сохраняет длину, иначе
  это ошибка, и строку трогать нельзя.

`convert` — то же замыкание, что использует `ReplacementFlow` (`TextConverter.convert`).

### Синтетический ввод

- Backspace: `KeyboardMonitor.press(keyCode: 51, holdMicroseconds: 1_000)`, `deleteCount` раз.
- Каждый символ `insert`: пара `keyDown`/`keyUp` со строкой из одного символа через
  `CGEventKeyboardSetUnicodeString`, код клавиши 0, флаги пустые, маркер `syntheticEventMarker`,
  удержание 1 мс.
- Все события — на фоновой очереди `replacementQueue`, как сейчас; фрагмент обновляется на главном
  потоке после серии.

### Журнал

Только: `Terminal replacement: len=<n> target=<id>`, исход (`replaced`, `layoutOnly(reason)`),
`interleaved input`. Ни фрагмента, ни символов, ни кодов клавиш.
