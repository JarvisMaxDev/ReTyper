# Quickstart: проверка замены в терминале

> Актуализация 2026-10-01: база 0.10.1, конституция 9.0.0, S4:A принят.
> См. [implementation.md](./implementation.md) для действующего дизайна и команд стенда.
> Старые спайки ниже сохраняются как воспроизводимые эксперименты, не как незакрытый S4-блокер.
> В release-командах `swift test/build` использовать `--build-system native` и получать
> каталог тем же `swift build --build-system native --show-bin-path`.
> Добавлены обязательные Enter0/10/30/80 и Typing0: никакой частично изменённой отправленной строки.

**Дата**: 2026-09-29 | **Контракт**: [contracts/terminal-hotkey.md](./contracts/terminal-hotkey.md)
| **Модель**: [data-model.md](./data-model.md)

Фактические результаты всех шагов записываются в `verification.md` этой фичи (создаётся первой
задачей). Шаг без записи считается невыполненным.

## Предусловия

- Поправка конституции 7.0.0 одобрена владельцем и внесена ([plan.md](./plan.md#предлагаемая-поправка-конституции-700)).
  Без неё реализация не начинается.
- macOS 12+, у ReTyper есть Accessibility и Input Monitoring.
- В «Active Keyboards» выбраны Polish и Russian – PC, «Switch Only Last Word» выключен, если
  сценарий не говорит иначе.
- [Терминал](https://support.apple.com/guide/terminal/welcome/mac), оболочка zsh, «Защищённый ввод
  с клавиатуры» выключен (Терминал → меню приложения).

## 1. Спайки до основной реализации

Каждый спайк — минимальный код в рабочей копии, не коммитится; результат и решение — в
`verification.md`. Провал S1 или S4 останавливает реализацию до решения владельца.

| # | Что проверить | Как | Успех |
|---|---------------|-----|-------|
| S1 | Терминал принимает символ из `CGEventKeyboardSetUnicodeString`, Backspace стирает одну кириллическую букву ([R4](./research.md#r4-как-ввести-исправленный-текст), [R5](./research.md#r5-сколько-символов-стирает-backspace-в-оболочке)) | В строке zsh набрать `ghbdtn`, послать 6 × Backspace и `привет` по одному символу; затем в строке `привет` послать 6 × Backspace | Первая строка `привет`, вторая пустая, приглашение не повреждено |
| S2 | Время серии ([R6](./research.md#r6-прерывание-во-время-замены-fr-009)) | Замерить серию 100 × Backspace + 100 символов с удержанием 1 мс | < 1 с (SC-004); в строке ровно 100 новых символов |
| S3 | Свежесть текущей раскладки ([R1](./research.md#r1-как-узнать-какой-символ-напечатан)) | Переключить раскладку хоткеем ReTyper и сразу (≤ 50 мс) нажать клавишу; сравнить ID раскладки в callback с новой | ID новой раскладки в 10 попытках из 10 |
| S4 | Защищённый ввод при запросе пароля ([R7](./research.md#r7-защищённый-ввод-и-пароли-fr-007)) | В Терминале выполнить `read -s x`, затем `sudo -k; sudo true`; во время ввода в другом окне выполнить `ioreg -l -w 0 \| grep kCGSSessionSecureInputPID` | PID Терминала в обоих случаях. Иначе — стоп, решение владельца |

## 2. Автоматические тесты

```bash
swift test
```

Ожидается: все тесты проходят, в том числе новые:
- `TypedFragmentTests` — добавление, Backspace, сброс, предел 256 и переполнение, `generation`,
  `replaceTail`.
- `TerminalKeyTests` — классификация по таблице
  [R2](./research.md#r2-какие-нажатия-пополняют-фрагмент-какие-сбрасывают) на системных
  раскладках, включая мёртвые клавиши German и French ([R3](./research.md#r3-мёртвые-клавиши)).
- `TerminalReplacementTests` — контракт `edit`: пустой/переполненный фрагмент, режим последнего
  слова, неопределённое направление, обратимость `ghbdtn` ↔ `привет` и `^)` ↔ `:)`.
- Существующие тесты фич 001 и 002 проходят без изменений.

## 3. Release-кандидат (принцип V)

Команды те же, что в [quickstart фичи 002, §2](../002-symbol-conversion/quickstart.md#2-release-кандидат-по-конституции-принцип-v),

CI публикуемой ревизии.

## 4. Автоматический стенд

```bash
Tools/ReTyperStand/run.sh            # обычные сценарии 1–11, как в v0.10.0 (SC-005, FR-015)
Tools/ReTyperStand/run.sh --terminal # новые терминальные сценарии
```

Терминальный режим ([R11](./research.md#r11-автоматическая-сквозная-проверка)) открывает окно
Терминала со строкой `vared`, печатает текст как пользователь, нажимает двойной ⌥ и Return и
сверяет, что получила оболочка. Покрывает сценарии User Story 1 (1–7) и User Story 2 (1, 3, 7),
длинный ввод и время замены 100 символов (T13, SC-004); по 10 повторов (SC-001, SC-002). Буфер
обмена на время прогона — RTF и текст (SC-003). Во время прогона ничего не печатать и не трогать мышь.

## 5. Ручная проверка (выполняет владелец)

В Терминале, zsh, Polish + Russian – PC. Для каждого сценария — ожидаемая строка, раскладка после
хоткея; затем Return и проверка, что оболочка получила ожидаемую строку (например, через
`echo <строка>`).

| # | Действия | Ожидается |
|---|----------|-----------|
| 1 | PL, набрать `echo ghbdtn`, хоткей | `echo привет`, RU |
| 2 | После 1 сразу хоткей | `echo ghbdtn`, PL |
| 3 | RU, набрать `сгкд -Ш`, хоткей | `curl -I`, PL |
| 4 | ↑ (команда из истории), дописать `ghbdtn`, хоткей | меняется только `ghbdtn` |
| 5 | «Только последнее слово» вкл., `git commit -m ghbdtn`, хоткей | меняется только `ghbdtn` |
| 6 | Набрать `ghbdtb`, Backspace, `n`, хоткей | `привет` |
| 7 | Набрать `ghbdtn`, ←, хоткей | строка без изменений, раскладка сменилась |
| 8 | Набрать `gi`, Tab (дополнение), хоткей | без изменений |
| 9 | Набрать `ghbdtn`, щёлкнуть мышью в окне, хоткей | без изменений |
| 10 | Набрать `ghbdtn`, ⌘T и обратно ⌘⇧[, хоткей | без изменений |
| 11 | `sudo -k; sudo true`, на запросе пароля набрать что-нибудь и нажать хоткей, затем ⌃C | в журнале нет замены; пароль не отправлен |
| 12 | Скопировать в буфер картинку, выполнить сценарий 1, вставить в Заметки | вставляется та же картинка (SC-003) |
| 13 | VS Code и WebStorm: обычный сценарий в редакторе и хоткей в панели терминала | как в v0.10.0 (SC-007) |
| 14 | vim в режиме вставки: набрать `ghbdtn`, хоткей | зафиксировать фактический результат; в критерии приёмки не входит |
| 15 | Набрать `ghbdtn`, ⌘V (в буфере любой текст), хоткей | строка без изменений (кроме вставленного), раскладка сменилась |
| 16 | Два окна Терминала на разных рабочих столах: в первом набрать `ghbdtn`, жестом перейти ко второму, хоткей | строки обоих окон без изменений, раскладка сменилась |

Сценарии 1–11, 15 и 16 — по 10 повторов (SC-001, SC-002). Свежий скриншот Терминала после сценария 1 —
визуальное подтверждение по принципу V.

## 6. Журнал

`~/Library/Caches/com.retyper.app/retyper.log` после всех сценариев:

- есть строки `Terminal replacement: len=… target=…` и исходы;
- во **всём** журнале нет набранного текста (SC-006, принцип I):
  `grep -n -F -e 'ghbdtn' -e 'привет' -e 'сгкд' -e 'curl' ~/Library/Caches/com.retyper.app/retyper.log`
  ничего не находит;
- `grep -rl -F 'ghbdtn' ~/Library/Caches/com.retyper.app ~/Library/Preferences/com.retyper.app.plist`
  ничего не находит.
