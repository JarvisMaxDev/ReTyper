Приватная часть хранится в Actions secret `TAP_DEPLOY_KEY` репозитория ReTyper; её содержимое в документацию/логи не включается. Ключ действует до отзыва, автоматического срока истечения нет.
- Workflow использует SSH только с указанным ключом: `IdentitiesOnly=yes`, `IdentityAgent=none`, `BatchMode=yes`; пользовательская SSH-конфигурация и общий known_hosts не используются. Ключ сервера GitHub закреплён по официальному Ed25519 fingerprint `SHA256:+DiY3wvvV6TuJJhbpZisF/zLDA0zPMSvHdkr4UvCOqU`, проверенному также через HTTPS API `/meta`.
- На runner приватный ключ создаётся в собственном каталоге с `umask 077`, исключается из окружения дочерних команд и удаляется EXIT-trap вместе с временным checkout. Секрет не передаётся в URL и не выводится shell tracing.
- Локальная проверка новым ключом без SSH-agent подтвердила чтение main и авторизованный `git push --dry-run` без изменения tap. Проверены синтаксис workflow и ранний отказ при пустом `TAP_DEPLOY_KEY`.

Эта правка имеет тип `ci`, не требует выпуска новой версии приложения. Фактические прогоны доступны в [Build & Release](https://github.com/JarvisMaxDev/ReTyper/actions/workflows/build.yml).
