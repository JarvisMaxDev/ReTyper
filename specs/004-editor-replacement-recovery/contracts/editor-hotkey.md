# Контракт: редакторный хоткей с метаданными

Дата: 2026-10-01. Конституция 8.0.0. [Результаты](../verification.md).
Предыдущий контракт подготовки — `editor-hotkey-ax-preparation.md`, он заменён этим протоколом.

| Наблюдение | Действие |
|---|---|
| Неподтверждённое поле, поиск, терминальная панель, защищённый ввод | Только смена раскладки, без probe-copy/редактирования |
| Свежий copy с `isFromEmptySelection=false` и одиночным непустым текстом | Преобразовать именно пользовательское выделение и вставить поверх него |
| Свежий copy с `isFromEmptySelection=true` | Отбросить текст; выделить штатными клавишами; повторно копировать и подтвердить настоящее выделение |
| После автовыделения по-прежнему empty | Не вставлять и не сдвигать каретку стрелкой вправо |
| Режим последнего слова и собственное выделение | Уменьшить его и ещё раз скопировать; фактический текст должен совпасть с ожидаемым словом |
| Ошибка/отсутствие/неподдержанная metadata, многокурсорность | Отказ от вставки, без общего слепого fallback |
| Сменился контекст или пользователь печатает | Отмена дальнейших команд; cleanup только подтверждённого собственного выделения в исходном поле |
| Clipboard изменён пользователем | Не затирать новую копию старым snapshot |

Настройки редактора не меняются; режим экранного диктора и фоновая подготовка не включаются.
Обычные не-VS-Code поля используют прежний поток. Преобразование — прежний TextConverter с
системными раскладками. Конкурентные изменения и пределы проверки описаны в отчёте;
отправка системного события не считается атомарной транзакцией с чужим редактором.

Проверенные примеры: `ghbdtn` → `привет`; `prefix [ghbdtn] suffix` → `prefix привет suffix`;
в режиме слова `hello ghbdtn` → `hello привет`; `^)` при Polish → `:)`. Начало строки/пустое
поле не получают вставки, многокурсорный результат не преобразуется этим адаптером.
