# Архив контракта: отклонённая AX-подготовка

Дата: 2026-09-30. [Спецификация](../spec.md), [архив модели](../data-model-ax-preparation.md).
Приложение не предоставляет внешнего API; контракт описывает пользовательские действия и
границу между подготовкой приложения и существующим механизмом замены.

## Поведение

| Состояние | Разрешено | Запрещено |
|---|---|---|
| Идёт подготовка | Смена раскладки, краткий статус «Подготовка редактора…» | Copy, Paste, изменение каретки/выделения, накопление хоткеев |
| Подготовка failed | Смена раскладки, «Не удалось подготовить редактор. Вернитесь в приложение и повторите» | Повторные AX-запросы на каждый хоткей, команды редактирования |
| Поле unverified после initialized / notNeeded | Смена раскладки, «Не удалось определить выделение. Текст не изменён» | Заявление о готовности, команды редактирования |
| Поле unsupported | Смена раскладки, «Это поле пока не поддерживается» | Обещание, что ожидание решит проблему, команды редактирования |
| Пригодный редактор, пользователь выделил текст | Копирование именно этого выделения и вставка поверх него | Автовыделение до начала строки, отдельный Backspace |
| Пригодный редактор, выделения нет | Стандартное выделение строки/слова; copy только после подтверждения ненулевого выделения | Копирование каретки или старого буфера |
| Настоящее пустое поле/начало строки | Смена раскладки | Дублирование строки, вставка старого буфера |
| Terminal, secure | Смена раскладки, если хоткей получен | Редакторные команды замены |
| Сменился контекст | Отмена дальнейших команд, восстановление собственного clipboard при неизменном changeCount | Paste либо снятие выделения в новом поле |

Статус подготовки — короткое неперехватывающее фокус сообщение существующего menu-bar
приложения, без системного уведомления, требующего нового разрешения. Оно показывается только
по хоткею и убирается через 3 с или при смене контекста; жизненный цикл см. FeedbackState в модели.

**Обязательные результаты для Polish + Russian – PC:**

- `ghbdtn` без выделения → `привет`.
- `prefix [ghbdtn] suffix` с выделением в скобках → `prefix [привет] suffix`
  (скобки показывают границы, не часть текста; после вставки каретка следует поведению редактора).
- `hello ghbdtn`, режим последнего слова → `hello привет`.
- `^)` при Polish → `:)`.
- `ghbdtn` с кареткой в начале строки → строка без изменений.

## Контракт подготовки

Вход: ApplicationIdentity и событие запуска/активации. Выход: состояние попытки подготовки.
AX-запросы выполняются вне главного потока и callback event tap. Ошибка первого запроса не
кешируется как успех. Отложенная callback проверяет живой процесс и token. Два запроса максимум,
единый бюджет ≤4 с. Никаких команд клавиатуры или чтения/записи настроек редактора.

У приложения без специального атрибута подготовка `notNeeded`: нативное поле проверяется обычным
путём без setter и задержки. Отсутствие атрибута не означает `eligibility=unsupported`.

## Контракт определения выделения — блокер

Вход: подготовленный процесс и текущий контекст. Выход: SelectionObservation.
**Достаточный критерий eligibility пока не подтверждён (P0-01).** До его подтверждения нельзя
реализовать этот интерфейс как `initialized && range != nil` и объявить план прошедшим гейт.

Приёмочный тест обязан раздельно хранить реальное выделение и ответ AX: оба могут отличаться.
Преобразование текста выполняет прежний TextConverter; оно не решает проблему источника текста.
