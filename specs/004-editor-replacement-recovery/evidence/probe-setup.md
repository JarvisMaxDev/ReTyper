# Воспроизводитель P0-01

Исходники: `$TMPDIR/opencode/retyper-004/Probe.swift`, `capture.mjs`; binary `probe`.
Это исследовательская программа вне production/test target. После отрицательного результата
она не переносится как готовый механизм подготовки.

1. Собрать `swiftc "$TMPDIR/opencode/retyper-004/Probe.swift" -o "$TMPDIR/opencode/retyper-004/probe"`.
2. Открыть единственный собственный `repro.txt` в отдельном экземпляре редактора с
   `--user-data-dir "$TMPDIR/opencode/retyper-004/profile" --disable-extensions --new-window
   --remote-debugging-port=9338`. Исходное содержимое — `prefix ghbdtn suffix`.
3. Определить именно PID основного процесса с этим user-data-dir; другие экземпляры не трогать.
4. `probe PID full OUTPUT_DIR`: начальная установка строки, сохранение, переход к началу,
   семь Right, шесть Shift+Right, независимый снимок, исходный хоткей, подготовка и снимок.
5. Для второго порядка: `probe PID setup-backward OUTPUT_DIR`, перезапустить только известный
   исходный ReTyper, вернуть фокус тестовому окну, `probe PID baseline OUTPUT_DIR`.
6. Во время подготовки после начального setup никакие команды выделения/редактирования не посылаются.

`capture.mjs` получает единственную page тестового процесса через localhost:9338/json/list и
отправляет только Page.captureScreenshot. Нет включения доменов Accessibility/DOM/Runtime,
инспектирования модели редактора или изменения его preferences. Состояние AX проверяется
до/после первого снимка, независимый эталон считывается визуально с PNG.

Тестовый профиль содержит `editor.accessibilitySupport=auto`, отключение телеметрии/обновлений
и welcome-страницы; пользовательский профиль не меняется. Capture не требует новых системных
разрешений. Скриншоты содержат исключительно собственную тестовую строку.

Ограничения: программа требует активного собственного окна с `repro.txt`; при чужом фокусе
останавливается до следующего ввода. Незавершённые попытки не засчитываются. Полный набор
10-повторных проверок не выполнен: первый корректный контрпример вызвал остановку.
