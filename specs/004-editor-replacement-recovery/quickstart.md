# Проверка текущего исправления

Дата: 2026-10-01. Это метаданный путь, не отклонённая AX-подготовка.

## Автоматические проверки

```bash
swift test --build-system native
bash scripts/test-build-path.sh
bash scripts/test-package-release.sh
swift build --build-system native -c release --arch arm64
swift build --build-system native -c release --arch x86_64
```

Использовать пути того же engine (`--show-bin-path`), собрать Universal Binary, проверить обе
архитектуры отдельными вызовами lipo, minos12 через vtool, codesign и hash запущенного bundle.
Нельзя брать старый `.build/debug` после сборки другим engine. Коммит/пуш не являются частью
этих команд; release pipeline запускается только после отдельного разрешения.

## Живой прогон

1. Запустить один свежий ReTyper, проверить его PID/путь/hash.
2. Выполнить `Tools/ReTyperStand/run.sh` — ожидается 11/11.
3. По [инструкции редакторного стенда](../../Tools/ReTyperStand/EDITOR-RECOVERY.md) открыть только
   собственный тестовый документ, прогнать настоящий хоткей, затем отрицательные сценарии.
4. Обязательно проверить первый случай после холодного запуска, частичное выделение в обе
   стороны, обычный пользовательский профиль, нативное приложение и несколько типов clipboard.
5. Для скорости использовать `--performance`, фиксировать наблюдаемый документ и раскладку,
   не только строку журнала. Во время прогона не печатать и не переключать окна.
6. Сохранить свежий скриншот, проверить отсутствие собственных тестовых строк в полном журнале,
   закрыть только тестовые окна, восстановить режим слова/раскладку/clipboard.

Прерванные и проваленные прогоны хранить отдельно от успешных. Текущие результаты и ограничения —
[verification.md](verification.md). Прежние P0-опыты сохранены в `quickstart-ax-preparation.md`.
