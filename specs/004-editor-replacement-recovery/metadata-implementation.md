# Текущий план: метаданные копирования вместо AX-подготовки

Дата: 2026-10-01. Основание: явное поручение владельца внедрять изменения до рабочего результата
после предложения узкого исключения и [опыта 80/80](evidence/metadata-alternative.md).
Конституция 8.0.0, принцип III. Это новая архитектура, прежние P0-гейты не объявляются пройденными.

## Механизм

- Только `com.microsoft.VSCode` и подтверждённое редакторное поле, не весь процесс без разбора.
  Кандидат фильтра: AXTextArea + DOM-класс `native-edit-context` или `inputarea`.
  Отсутствие подтверждённых признаков даёт отказ. На живой машине подтверждены: editor
  AXTextArea/native-edit-context, поиск AXTextArea/input, терминал AXTextField/xterm-helper-textarea.
- Контекст операции — запуск процесса, окно, фокусный элемент и revision внешнего ввода.
  Мышь/клавиатура/смена активного приложения инвалидируют операцию, не жест хоткея.
- Probe-copy не изменяет текст и выделение. Clipboard snapshot сохраняет все типы данных.
- Читать только свежую генерацию clipboard, содержащую источник vscode-file и корректный
  `vscode-editor-data` version 1, UUID, строго булев isFromEmptySelection, multicursorText=null.
- `false` + непустой текст → настоящее выделение; не расширять его, даже в режиме последнего слова.
- `true` → результат копирования строки отбрасывается. Штатное выделение до начала строки,
  новый copy, обязательно `false`. Для последнего слова — уменьшение выделения и повторное
  подтверждение точного фрагмента до paste.
- Нет metadata/некорректный формат/многокурсорность/смена контекста/secure input → без вставки.
- Перед paste повторно проверяются контекст и clipboard changeCount; чужое копирование не
  перезаписывается восстановлением snapshot. Вставка поверх выделения, без предварительного Delete.
- Clipboard восстанавливается по текущему changeCount с существующей задержкой после paste.
- Общий путь остальных приложений сохраняется; преобразователь системных раскладок не меняется.

## Файлы

- `EditorCopyMetadata.swift`: ограниченный парсер Pickle/JSON; нет доступа к системе или логирования текста.
- `EditorMetadataFlow.swift`: проверяемая последовательность probe/select/copy/convert/paste.
- `SystemReplacementHost.swift`: конкретный получатель, clipboard, системный secure input.
- `AppDelegate.swift`: выбор стратегии только для VS Code и инвалидирование по активации.
- `KeyboardMonitor.swift`: revision внешнего ввода; событий жеста мышь не отменяет.
- `build.sh`: источник бинарника определяется тем же build engine, не старым жёстким путём.

## Принципиальные ограничения

Формат metadata — внутренний контракт редактора, поэтому парсер отвергает неподдержанную версию,
а не угадывает. Поддержка других редакторов/клонов не подразумевается по похожему названию.
Метаданные сами по себе не удостоверяют чужой процесс: обязательна проверка контекста и свежести.
Глобальная отправка событий сохраняет системные ограничения атомарности; живые гонки M008
должны быть проверены до допуска кандидата.
